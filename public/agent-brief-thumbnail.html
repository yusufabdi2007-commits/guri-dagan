Every Video Follows This Script

The thumbnail must tease the Hook — the first 3 seconds. Thumbnail and hook work together to pull the viewer in.

0 – 3 seconds
Hook
Pattern interrupt. Bold statement, shock, question, or relatable moment. This is what the thumbnail must deliver.
2
3 – 10 seconds
Problem

The core method or practical tip the parent can use.
5
45 – 60 seconds

One concrete thing to do today. Specific and immediate.

CTA
Follow, comment, book a free call, join the program.
4
Thumbnail Formulas That Work

For every video the agent generates 3 thumbnail concepts, each using a different formula. Coach picks one winner.

Formula 01
Question
"Ma garanaysaa?" — Do you know?
Surprised or curious face. Creates an open loop the viewer must close by watching.
Formula 02
Warning
"Jooji!" — Stop doing this
Serious face, red accent element. Fear of loss. "You're making this mistake right now."
Formula 03
Transformation
"Isbedel" — Change
Warm, hopeful expression. Before/after concept. Promises a specific outcome for the child.
Formula 04
Secret / Insider
"Qarsoon" — Hidden
Leaning-in pose, whisper energy. "Most parents don't know this." Exclusivity drive.
Formula 05
Number / List
"3 Hab" — 3 Ways  |  "5 Qaab" — 5 Methods
Confident smile. Specific number makes the content feel structured and completable. Works best for tips-based videos.
5
Design Rules for Every Thumbnail
🖺
Text Overlay — Max 5 Words
All-caps or title case. High contrast against face/background. The text and the hook must say the same thing in different ways.
🌍
Language — Always Somali
Never transliterate. Never alter Somali text. Write it exactly. The audience reads Somali — English text kills CTR for this channel.
📷
Face Expression is Everything
Coach must be clearly visible, expressive, and facing camera. Describe exact expression: shocked, warm, serious, proud, urgent.
📱
Mobile-First — 9:16 Format
Vertical frame. Text should sit in the lower or upper third — never covering the face. Must be readable at thumb size on a phone screen.
🌟
Emotion Tags
Assign one: Curiosity / Fear / Hope / Pride / Shock / Warmth. Curiosity and Fear outperform for this audience.
🎉
Program Tag Required
Every thumbnail concept must be tagged to one of the 5 programs. This allows the system to learn which program's visuals get the most clicks.
6
Database — Build This Table

Add to the existing Supabase database. The app already has videos, content_performance, and batch_posts tables.

thumbnail_concepts
id UUID PRIMARY KEY DEFAULT gen_random_uuid()
user_id UUID REFERENCES auth.users
video_id UUID REFERENCES videos(id) — nullable for pre-recording
batch_post_id UUID REFERENCES batch_posts(id) — links to scheduled post
title_text TEXT Somali overlay text — max 5 words
visual_concept TEXT Pose / expression / background direction
emotion_tag TEXT curiosity / fear / hope / pride / shock / warmth
formula TEXT question / warning / transformation / secret / number
program TEXT One of the 5 program names
is_winner BOOLEAN DEFAULT false — coach marks which concept was used
ctr_result NUMERIC Logged after posting — % click-through rate
created_at TIMESTAMPTZ DEFAULT now()
7
What to Build — Feature Spec
Route: /thumbnails  |  API: /api/thumbnails (GET list, POST generate, PATCH mark winner, PATCH log CTR)
Step 1 — Pick a Video

Show all scheduled batch posts from batch_posts table. Coach taps a video title to generate thumbnail concepts for it.

Step 2 — AI Generates 3 Concepts

Call AI with the video title, hook, and program. Returns 3 concepts — each with a different formula, Somali title text, visual direction, and emotion tag.

Step 3 — Coach Picks Winner

Coach taps "Use this one" on a concept. is_winner = true saved to DB. The selected concept becomes the filming brief.

Step 4 — Log CTR After Posting

After the video goes live, coach opens the card and enters the CTR %. Saved to ctr_result. Over time the system learns which formulas win.

Future Intelligence (Phase 2)

Once enough CTR data is collected, the AI prompt should include "Your top performing formula for [program] is [formula] with avg CTR of X% — lean toward this style." This creates a self-improving loop.
